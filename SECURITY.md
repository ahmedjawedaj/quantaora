# Security Policy

## Supported Version

Quantaora is an active public alpha. Security fixes are applied to the latest code on `main` and the current deployment at [quantaora.vercel.app](https://quantaora.vercel.app).

## Report a Vulnerability

Do not open a public issue for a suspected security or privacy vulnerability.

Use the repository's **Security** tab and select **Report a vulnerability** to create a private GitHub Security Advisory. Include:

- A clear description of the issue and its impact
- Reproduction steps or a minimal proof of concept
- Affected routes, files, or versions
- Any suggested mitigation

Please avoid accessing or modifying data that does not belong to you, disrupting the public service, or publishing details before a fix is available. The maintainer will acknowledge a valid report as soon as practical and coordinate remediation and disclosure through the private advisory.

## Privacy

The current app uses browser-local storage for learner state and does not require an account. Reports must not contain children's personal information, screenshots with identifying details, credentials, or private browser data.
