# Quantaora Web App

This directory contains the React, TypeScript, and Three.js application for [Quantaora](https://quantaora.vercel.app).

Project documentation, contribution guidance, licensing, curriculum sources, and CI/CD configuration live at the [repository root](../README.md).

## Development

```bash
npm ci
npm run dev
```

## Validation

```bash
npm run lint
npm test
npm run codegen:check
npm run quality:gaps
npm run assets:check
npm run build
```

Node.js 22 or newer is required. The current alpha does not require a backend or environment variables for core local development.
