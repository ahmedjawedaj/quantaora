# Asset licence register

Every third-party asset shipped in `quantaora-app/public/` must have a row here **before** it is
referenced by code. Licences are per-file, not per-source — NIH 3D in particular hosts user uploads
under differing terms, so "it came from NIH" proves nothing on its own.

Run `npm run assets:check` from `quantaora-app/` after adding or changing a registered model.
Use `PAID_RELEASE=1 npm run assets:check` before any paid launch; that mode blocks `NC-RISK` and
`REVIEW` assets.

> Procurement context: the [STEM OS asset catalogue](supplier/stem-os-asset-catalogue.md) is the
> source of truth for *candidate* heroes (112 P0 rows with per-asset licence flags). This file is
> the register of *actual* assets — a row is added here only when a candidate is imported. The
> catalogue's **CC BY-NC/CC BY-NC-ND rows are NC-RISK and must not ship in a paid release**;
> see it for the 5 named offenders and the CC BY import order (Heart → Lungs → Brain → Cell →
> DNA → Abacus).

Status key:
- **CLEAR** — commercial use permitted, no attribution burden beyond a credits line.
- **ATTRIB** — commercial use permitted, attribution required in-app.
- **NC-RISK** — non-commercial only. Usable while Quantaora is unmonetised; **must be replaced
  before any paid launch**.
- **REVIEW** — shipped only as a quality/prototype baseline. Needs exact source, licence text,
  commercial-use permission, redistribution permission, and attribution requirements recorded before
  a paid release.

## Known traps (do not use without a per-file check)

- **NIH 3D** — user-upload repository. Licences vary per entry and NIH explicitly does not enforce
  contributor terms. Two of our three NIH files are non-commercial; one is CC0. Always open the
  entry page and read the licence field.
- **PhET Interactive Simulations** — relicensed **2026-03-29**. Sims published before that date are
  CC BY 4.0 (commercial OK); everything published on or after is **CC BY-NC**. Source repos are
  GPL-3.0 (copyleft); only the common libraries (`scenery`, `joist`, `sun`, `axon`…) are MIT.
- **GeoGebra, Desmos, oPhysics, The Physics Aviary, Wolfram Demonstrations** — all require a paid
  agreement or are non-commercial/all-rights-reserved. Use JSXGraph (LGPL) or Mafs (MIT) instead.
- **Stellarium Web Engine** — AGPL-3.0. Network copyleft; incompatible with a proprietary app.
- **Thingiverse / Free3D / TurboSquid-free / CGTrader-free / AI text-to-3D generators** —
  royalty-free-with-terms or unverifiable provenance. Not open licences.
