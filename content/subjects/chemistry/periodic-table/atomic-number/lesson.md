# Atomic Number

*Chemistry > Periodic Table > Reading the Periodic Table > The numbers on an element card > Atomic Number*

The atomic number is the number of protons in an element's atoms. It is the element's identity number, and it is what orders the whole periodic table.

## 1. See it

Look at the 3D model: a large element card floating in front of a section of the periodic table. Tap the `hs-atomic-number` hotspot to open its card. Notice the atomic number printed at the top — a clean whole number — with a small nucleus model showing that many protons inside it.

## 2. Touch it

Rotate the card and the table behind it. Toggle the 'proton count' layer to pop the protons out of the nucleus one at a time and count them — the count matches the atomic number exactly. Toggle the 'table order' layer to highlight this element's box in its row on the table.

## 3. Name it

Tap `hs-atomic-number` to label the atomic number on the card. Tap `hs-proton-count` to label the matching protons inside the nucleus, and `hs-table-position` to label the element's box on the periodic table.

## 4. Explain what it does

Walk through what the atomic number does: it counts the protons, it is the element's unique identity number, and it places the element in order on the periodic table. In a neutral atom it also equals the electron count, and it never changes during reactions.

**Prediction prompt:** Before you toggle the proton-count layer on, predict whether the number of protons shown will match the atomic number on the card — then count them.

## 5. See where it belongs

The atomic number belongs to every **element** as its identity. From there it connects upward: it orders the **periodic table**, and it connects down to the **proton**, the particle it counts in the nucleus.

## 6. Compare it

Compare the **atomic number** with the **atomic mass**. The atomic number counts protons — a clean whole number that names the element. The atomic mass averages the mass of all the element's atoms, including neutrons, so it is usually a decimal. Two numbers on the same card, doing two very different jobs.

## 7. Use it in a task

Use the model to answer a real question: *If an element has atomic number 8, how many protons does each of its atoms have — and how many electrons does a neutral atom have?* Use the proton-count layer to verify.

**Practice item:** On the card, point to the atomic number and explain aloud why no two elements can ever share it.

## 8. Review it later

**Checkpoint:** What does the atomic number count, and how is the periodic table ordered using it?
