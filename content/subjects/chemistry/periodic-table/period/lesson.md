# Period

*Chemistry > Periodic Table > Reading the Periodic Table > How the table is arranged > Period*

A period is a horizontal row of the periodic table. Elements in a row share the same number of electron shells, and moving across a row carries you from metals to nonmetals.

## 1. See it

Look at the 3D model: a section of the periodic table with one entire row glowing. Tap the `hs-period-row` hotspot to open its card. Notice that the elements in the row sit side by side, all in a line.

## 2. Touch it

Rotate the table section. Toggle the 'shell count' layer to show each element in the row with its shells — they all have the same number. Toggle the 'character sweep' layer to color the row's tiles from warm metal tones on the left to cool nonmetal tones on the right.

## 3. Name it

Tap `hs-period-row` to label the row as a period, `hs-period-shells` to label the shared shell count, and `hs-period-sweep` to label the metal-to-nonmetal shift across the row.

## 4. Explain what it does

Walk through how a period works: the row number tells you how many shells its elements have, and moving left to right across the row shifts the elements from metals through metalloids to nonmetals. Unlike groups, the elements in a period do not behave alike.

**Prediction prompt:** Before you toggle the shell-count layer on, predict whether every element in the row will show the same number of shells — then count them.

## 5. See where it belongs

The period belongs to the **periodic table** as one of its 7 horizontal rows. From there it connects downward to the **electron shell** it counts, and across to the **metals** and **nonmetals** that split each row.

## 6. Compare it

Compare a **period** with a **group**. A period is a horizontal row — same shell count, sliding from metals to nonmetals. A group is a vertical column — same valence electrons, similar behavior. Rows are a journey; columns are a family.

## 7. Use it in a task

Use the model to answer a real question: *Sodium sits at the left of period 3. Based on its position, is it a metal or a nonmetal — and how many shells does it have?* Use the row and the character sweep to decide.

**Practice item:** On the row, point to the metal end and the nonmetal end, and explain aloud what the period number tells you about both.

## 8. Review it later

**Checkpoint:** What does the period number tell you, and what changes as you move across a period from left to right?
