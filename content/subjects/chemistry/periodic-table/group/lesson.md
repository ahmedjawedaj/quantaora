# Group

*Chemistry > Periodic Table > Reading the Periodic Table > How the table is arranged > Group*

A group is a vertical column of the periodic table. Its elements share the same number of valence electrons — and therefore behave alike.

## 1. See it

Look at the 3D model: a section of the periodic table with one entire column glowing. Tap the `hs-group-column` hotspot to open its card. Notice that every element in the column lines up vertically, one above another.

## 2. Touch it

Rotate the table section. Toggle the 'valence highlight' layer to show each element in the column with its outer shell — count the valence electrons and see they match across the whole column. Toggle the 'reactivity meter' layer to see a small bar beside each element showing they share a similar reactivity level.

## 3. Name it

Tap `hs-group-column` to label the column as a group, `hs-group-elements` to label a few members of the group, and `hs-group-valence` to label the shared valence-electron count that binds them.

## 4. Explain what it does

Walk through why a group works: elements in a vertical column share the same number of valence electrons, and because valence electrons control bonding, the whole column behaves alike. Group 1 elements are all reactive metals; group 18 elements are all unreactive gases.

**Prediction prompt:** Before you toggle the valence-highlight layer on, predict whether every element in the column will show the same number of valence electrons — then count them.

## 5. See where it belongs

The group belongs to the **periodic table** as one of its 18 columns. From there it connects downward to the **valence electrons** that create the similarity, and upward to whole families like the **alkali metals** and **noble gases**.

## 6. Compare it

Compare a **group** with a **period**. A group is a vertical column — elements stacked above and below that share valence electrons and behavior. A period is a horizontal row — elements side by side that share the same number of shells. Columns group behavior; rows count shells.

## 7. Use it in a task

Use the model to answer a real question: *If you discovered a brand-new element in Group 1, what would you predict about its valence electrons and how reactive it would be?* Use the column and the valence layer to make your prediction.

**Practice item:** On the column, point to two different elements and explain aloud the one thing they share that makes them a group.

## 8. Review it later

**Checkpoint:** What is a group on the periodic table, and why do elements in the same group behave alike?
