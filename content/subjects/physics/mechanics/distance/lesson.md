# Distance

*Physics > Mechanics > Describing Motion > Position and Displacement*

Distance is the total length of a path — every bend, every detour, every meter you actually cover. This model lets you drag a character around an obstacle course, watch the distance counter climb, and compare that against the short straight line being measured in the same scene.

## 1. See it

Look at the 3D model: a flat course with two landmarks — a start gate and a finish gate — plus cones and turns laid between them. A little hiker character stands at the start. A long thread-like line connects to the hiker, and a big readout counts up. Tap `hs-path-distance` to see the full length update, `hs-start` to mark the start, and `hs-finish` to mark the finish.

## 2. Touch it

Rotate to see the whole course. Drag the hiker along the winding path and watch the distance counter tick up with every meter — around cones, through the archway, over the bridge. Then flip to the shortcut layer and drag the hiker straight from start to finish. Feel how fast the counter stops climbing compared with the winding route.

## 3. Name it

Tap `hs-path-distance` to label 'distance — the full length of the path,' `hs-start` to label the starting point, `hs-finish` to label the stopping point, and `hs-straight-line` to label the displacement shortcut that is now drawn beside the course.

## 4. Explain what it does

Distance counts the total length of the path an object actually travels. It's a plain number — a scalar — so it's always positive and can only grow as you move. Winding route 12 m, straight shortcut 4 m: both are real, but distance is the full 12, because distance is about covering ground, not changing places.

## 5. See where it belongs

Distance lives in Mechanics, inside Describing Motion, sitting right next to position and displacement. It's the upstream input to speed (speed = distance ÷ time), so getting distance right is the foundation for every time measurement in this unit.

**Prediction prompt:** If you walk a square where each side is 10 m — all the way around back to start — what will the distance counter read when you return? Predict it before you let the hiker finish the loop.

## 6. Compare it

Compare distance with displacement. Distance — total path length, a scalar, always positive. Displacement — straight-line from start to finish, a vector, can be zero. Fork roads: walk 4 m forward then 4 m back: distance = 8 m, displacement = 0 m. The comparison models in one scene show exactly that split.

## 7. Use it in a task

Use the model to settle an argument: *Two friends race. One covers the winding path start to finish. The other takes a straight shortcut. The course counter says the winding path is 35 m. Which friend traveled more distance, and what is the displacement of the other friend?* Read it off the straight-line arrow.

**Practice item:** Set the model on the loop course. Drive the hiker once around and back to the start gate, then state the distance traveled and the displacement from where it began.

## 8. Review it later

**Checkpoint:** What is distance, what units do we use, and why is it usually a larger number than the straight-line distance between two points?
