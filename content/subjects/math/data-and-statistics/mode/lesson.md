# Mode

The mode is the value that appears most often in a dataset.

## 1. See it

Look at the 3D model: a survey table with a row of favorite-color chips — Blue, Red, Red, Blue, Green, Red. Above each color a counter shows how many times it appears. The Red column stands tallest with 3 counters. Tap `hs-mode-chip` to label the Red chip.

## 2. Touch it

Rotate and zoom in. Tap the piles to add more chips — the counters tick up and the tallest column shifts as the counts change. Press 'tie' and two colors reach the same top count, both glowing as two modes. Press 'reset' and let every color end with equal counts so the dataset has no mode.

## 3. Name it

Tap `hs-mode-chip` to label the winning value, `hs-counter` to label the count of that value, and `hs-tally-board` to label the whole board.

## 4. Explain what it does

The mode is found purely by counting: whoever appears most wins. Counts, not arithmetic, decide it. When two values tie for the top, both are modes. When every value appears equally, there is no mode — this happens in small datasets.

## 5. See where it belongs

The mode is the 'most popular' summary in Data And Statistics, side by side with the mean and median. It is the only one that works on colors, words, and categories, which is why surveys and shops love it.

**Prediction prompt:** Before you add another Blue chip, predict which color will still hold the mode.

## 6. Compare it

Compare the mode with the mean of the chips. The mean would need the colors coded into numbers and added; the mode just counts which appears most. On a bar chart, the mode is simply the tallest bar.

## 7. Use it in a task

Use the model for a store tally: count the sales of sizes S, M, L, XL (two chips each color). Add chips for the sizes customers actually bought: M, M, L — then read which size is the mode, so the shop knows what to restock most.

**Practice item:** On the model, make Blue appear three times and Red twice, then state which color is the mode.

## 8. Review it later

**Checkpoint:** What is the mode, and what do you do when there is a tie or when there is no mode?
