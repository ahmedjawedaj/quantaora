# Table

A table organizes data points into rows and columns so they are easy to read and compare.

## 1. See it

Look at the 3D model: a class scoreboard standing on a board. It is a grid with a header row and three columns: Name, Score, and Team. Five rows hold five students. Tap `hs-table-header` to label the header.

## 2. Touch it

Rotate and zoom in. Trace your finger across a row — each row highlights as one student's full record. Press 'sort by score' and the rows re-order themselves tallest to lowest score. Tap a cell and press 'highlight' to isolate one value; then press 'to chart' and the scores pop out as bars beside the table.

## 3. Name it

Tap `hs-table-header` to label the header row, `hs-row` to label a row, and `hs-column` to label a column.

## 4. Explain what it does

A table stores each data point as a cell at the meeting of a row and a column. Rows run across and hold one record each; columns run down and hold one attribute each. The header names the columns so every cell has meaning.

## 5. See where it belongs

Tables sit between raw data and charts in the data pipeline. Data points fill the cells; the table's numbers then feed bar charts, line graphs, and statistics like the mean and median.

**Prediction prompt:** Before you press sort by score, predict which student's name will be at the top of the new order.

## 6. Compare it

Compare the table with a bar chart of the same scores. The table lists exact numbers like 92 and 74; the chart shows those same numbers as bar heights. The table is precise, the chart is quick to compare.

## 7. Use it in a task

Use the model to read a bus timetable: look up the departure for the 3:15 bus in the Time column, then read its destination from the same row. Find the next bus after 2:00 by scanning down the Time column.

**Practice item:** On the model, highlight the cell for Mia's score, state the row and column that pinpoint it, then read the mean of all scores.

## 8. Review it later

**Checkpoint:** What do rows, columns, and the header do in a table, and how do you read one specific value?
