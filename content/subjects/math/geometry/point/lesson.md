# Point

A point marks one exact location — a dot with no size.

## 1. See it

Look at the 3D model: a small board showing a flat plane. A single dot sits near the center with the label 'A' beside it. A magnifying glass ring around the dot shows it has no width. Tap `hs-point-a` to label the point.

## 2. Touch it

Rotate and zoom in. Tap the plane to add more points, one at a time — each new dot gets a letter: B, C, D. Drag a point to slide it to a new location. Press 'plot' and a grid appears so you can drop point A at a specific row and column.

## 3. Name it

Tap `hs-point-a` to label the point, `hs-dot` to label the dot that shows it, and `hs-plane` to label the flat surface it sits on.

## 4. Explain what it does

A point is an exact location with no length, width, or thickness. The dot you draw is just a symbol for it — the point itself is pure position. On a grid every point has a spot: row and column tell exactly where it lives.

## 5. See where it belongs

Points are the building blocks of geometry. A line is a straight path of points; a segment is the stretch between two points; an angle's vertex is the point where two rays meet. Every shape you will meet is made of points.

**Prediction prompt:** Before you press plot, predict how you will describe where point A sits on the grid.

## 6. Compare it

Compare a point with a dot. The dot is a visible mark with thickness — but the point is the exact location it marks, which has no size. Compare a point with a line: the line extends forever through points, while the point stays in one place.

## 7. Use it in a task

Use the model to mark a map: find the school's location at row 3, column 5 and drop point A there. Then mark the park at row 1, column 2 as point B. Which is closer to the corner of the board?

**Practice item:** On the model, drop three points A, B, C in a triangle arrangement and describe each one's position on the grid.

## 8. Review it later

**Checkpoint:** What is a point, how is it shown, and how are points used to build a line and an angle?
