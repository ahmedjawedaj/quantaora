# Place Value

Place value means a digit's worth depends on its position. A 5 in the hundreds place is 500; a 5 in the ones place is just 5.

## 1. See it

Look at the 3D model: three place-value columns — hundreds, tens, ones — shown as stacks of base-ten blocks. Below each column sits the digit for the number 573, so the blocks match the written digits dot for block.

## 2. Touch it

Rotate the block columns and zoom in. Tap `hs-blocks` to highlight the base-ten blocks. Grab a bundle of ten ones from the ones column and slide it into the tens column — watch the app regroup it into a single ten block. Now push ten tens into the hundreds column to see a hundred block form.

## 3. Name it

Tap `hs-hundreds` to label the hundreds position, `hs-tens` to label the tens position, `hs-ones` to label the ones position, and `hs-digit-card` to label the written digit that each column shows.

## 4. Explain what it does

The value of a digit is its digit times its place. Each position left is worth ten times the one before it. So 573 = 5 hundreds + 7 tens + 3 ones. When a column reaches ten, it "carries" or regroups into one of the next column.

## 5. See where it belongs

Place value belongs to Number Sense. It explains the structure hiding inside every written number — ones, tens, hundreds, thousands. From here it drives addition, subtraction, multiplication, and later decimals.

**Practice item:** Using the blocks, build the number with 4 hundreds, 3 tens, and 6 ones. Say the number aloud, then read it out digit by digit.

## 6. Compare it

Compare a place-value number with a tally count. A tally just counts one-by-one with no position. Place value encodes the same quantity in far fewer characters by giving each position a place worth.

## 7. Use it in a task

Use the columns to solve a real question: *is 3 in the number 350 the same value as the 3 in 35?* Explain by pointing to each digit's column on the model — the same digit, different place, different worth.

**Practice item:** Add using regrouping: 36 + 27. Use the blocks to combine six and seven ones, and show how the extra ten carries to the tens column.

## 8. Review it later

**Checkpoint:** Write 859 in expanded form (hundreds + tens + ones) and explain what the digit 5 is worth and why.
