# Number Line

A line with equally spaced marks showing numbers in order. Numbers grow to the right and shrink to the left, with zero as the middle reference.

## 1. See it

Look at the 3D model: a clean horizontal number line floating in frame with equally spaced tick marks and the numbers −5 through 5. Zero sits in the center, positives run right, negatives run left.

## 2. Touch it

Rotate the line and zoom in. Tap the `hs-zero-reference` hotspot to highlight zero. Use the jump control to drop a marker with an arrow and count label, then drag it along the line to make jumps between ticks. Notice every gap between consecutive ticks is exactly the same length.

## 3. Name it

Tap `hs-minus-spacing` to label the equal tick marks, `hs-positive-side` to label the positive half, `hs-negative-side` to label the negative half (left of zero), and `hs-zero-reference` to label the zero reference.

## 4. Explain what it does

The number line is an equally-spaced map of numbers. Because every gap is the same, it shows both order (right = bigger) and distance (how far apart). Addition becomes a jump right; subtraction becomes a jump left.

## 5. See where it belongs

The number line belongs to Number Sense And Arithmetic. It is the anchor for ordering, comparing, place value, addition and subtraction, and it stretches left of zero into negative numbers.

## 6. Compare it

Compare a number line with an ordinary labeled chart. A number line places each number at a scaled position along an equally spaced line, showing order and magnitude. A chart lists numbers in order but does not show spatial size or distance.

## 7. Use it in a task

Mirror the marker: start at 2 and jump right 3 (land 5), then start at 5 and jump left 2 (land 3). Which landing point is smaller? Read both positions on the line to confirm.

**Practice item:** Start the marker at 7 and jump left 4. Describe what the landing position (3) represents as a subtraction fact: 7 − 4 = 3.

## 8. Review it later

**Checkpoint:** On the number line, why is 8 greater than 3? Which direction do you step to add, and which direction to subtract?
